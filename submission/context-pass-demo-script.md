# Context Pass — extended live-demo script

The submitted cinematic cut is 28 seconds and lives at `context-pass-demo.mp4`. This longer script is retained for a live walkthrough or a replacement screen recording if desired.

## Recording notes

- Record only the interactive demo panel after a two-second opening view of the full page.
- Keep the cursor still while speaking; move only when the next action is named.
- Use one continuous take. Target 65–75 seconds.
- Do not describe implementation details in the video.

## Script

**0–08 seconds — Meeting**

“Tomorrow I’m meeting my thesis supervisor. A meeting copilot could help—but it should not need my inbox, contact book, and every private note.”

Click **Ask Meeting Copilot to Prepare**.

**08–19 seconds — Request**

“Through AI Passport, the copilot asks for a specific purpose, person, three fields, and thirty minutes of access. A request is a question, not automatic permission.”

Click **Review Exact Fields**.

**19–36 seconds — Approval**

“I can inspect the actual values before sharing. Relationship summary, commitments, and meeting goals are useful. This personal reflection is structurally locked and cannot enter the pass.”

Click **Approve One-Meeting Pass**.

**36–49 seconds — Brief**

“The copilot creates a useful brief from only those approved fields. It never receives my raw notebook, inbox, or contact book.”

Click **View Access Receipt**.

**49–61 seconds — Receipt**

“AI Passport shows who read what, why, and when access expires. Any new memory would return as a draft that I must review.”

Click **Revoke Access Now**, then **Copilot Tries Again**.

**61–72 seconds — Denial and close**

“The retry is denied. Useful context travels across tools, but control stays with the person. That is Context Pass.”
